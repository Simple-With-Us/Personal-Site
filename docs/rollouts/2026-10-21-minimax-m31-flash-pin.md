# 2026-10-21 — Pin Fleet Autofix to MiniMax-M3.1-Flash and Trust the swu-* Fleet Bots

## Summary

The fleet autofix lanes now bill the `MiniMax-M3.1-Flash` model id on both routes they use.  `.github/pr-autofix-trusted.yml` moves off the retired `MiniMax-M3.1-Flash-Preview` id, `.github/workflows/claude-code-autofix.yml` passes `model: MiniMax-M3.1-Flash` explicitly so it never inherits the pinned reusable workflow's Preview default, and `.github/workflows/kody-fleet-autofix.yml` runs `MiniMax-M3.1-Flash` against the OpenAI-compatible endpoint `https://api.minimax.io/v1` under the renamed display name `Kody MiniMax M3.1 Flash Fix Proposals`.

The owner ruling of 2026-10-20 trusts every `swu-*` fleet bot, so `allowed_bots` in `claude-code-autofix.yml` grows to the 40 confirmed `swu-*` app installations in the organization, each in bare and `[bot]` form, alongside the Codex, Kody, Cursor, Claude, and Sentry identities.  The autofix prompt was updated to name the same set, so the allowlist and the prompt agree.

Branch: `autofix/minimax-flash-and-swu-bots`.  Pull request [#225](https://github.com/Simple-With-Us/Personal-Site/pull/225).

## Verification

`https://api.minimax.io/v1/models` lists `MiniMax-M3.1-Flash`, and a synthetic one-word canary against `https://api.minimax.io/v1/chat/completions` returned HTTP 200 with `model: MiniMax-M3.1-Flash`.  The id therefore resolves on the OpenAI-compatible route that the Kody lane bills, not only on the Anthropic-compatible route.

## Open fleet items

- A per-repository `daily_attempt_limit` for the Claude Code autofix lane is parked on the owner's fleet-budget decision.  The shared reusable workflow takes no per-repo cap input, so that cap belongs in the reusable helper and in every repository's `pr-autofix-trusted.yml`, not in this repository alone.
- `.github/workflows/kody-fleet-autofix.yml` is generated by `congress-trading-shared/.github/kody-autofix/generate-caller.mjs`, whose template still hardcodes the old display name.  Regenerating the caller restores `Kody MiniMax M3 Fix Proposals`, so the generator should derive the name from the model, or keep it model-agnostic, in `congress-trading-shared`.
- `allowed_bots` is a hand-maintained enumeration with no prefix support, so a newly installed fleet app bot is denied silently rather than loudly.
