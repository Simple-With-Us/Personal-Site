# Public page UI polish

## Summary

The public portfolio pages get a contained spacing, contrast, and missing-state pass.  Buttons use title case and a 44px target.  Visitor-facing sentences use a no-break space followed by a normal space.

## What changed

- Hero actions sit below the tagline.  `Explore All Apps`, `View Activity`, and `Contact` are 44px title-case buttons.
- The activity date and `See Full Activity` no longer share one line.  Day controls and rows are 44px.  Section labels read `Merged pull requests`, `Issues opened`, and `Issues closed`.  Loading, error, and empty copy is plain English.
- `Terms of Service` uses the muted text color at 14px with a 44px target.  On a phone the social icons use the full footer width.
- The phone menu scrolls inside the viewport, and its rows are 44px.  The desktop menu is labeled `Social`.
- Media has a `Spaceport3D` heading.  `Load Model`, `Open Model`, `Open Channel`, and each `Public Source` row are 44px.
- An unknown address shows a page with `Back to Home`.  Short pages keep the footer at the bottom of the viewport.
- The signed-out admin buttons use the shared button.  The owner panel uses `bg-bg-subtle` where `bg-bg-muted` did not exist.
- The error page uses the site colors and a `Back to Home` link.
- A `Skip to Content` link is the first keyboard stop.

## Left in place

The light theme stays.  Auth calls, the activity feed URL, and the operator start site are unchanged.
